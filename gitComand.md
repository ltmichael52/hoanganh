# Luồng triên khai web:
Note: Repo : repository = kho lưu trữ

Thiết bị cá nhân (Local repo) <--> Github (remote repo) <--> Server(Cloud) <--> Domain(Tên miền)

# Một số lệnh git
1. Git init: Khởi tạo git
2. Git remote add origin <URL> : Liên kết với remote repo
3. Git add . : thêm tất cả file vào khu vực staging
4. Git commit -m "Message" : thêm thông điệp cho lệnh commit 
5. Git push origin <branch> : Đẩy code lên nhánh nào đó
6. Git pull origin <branch> : Lấy code từ nhánh nào đó
